# FDTD 시뮬레이터 GUI

PyQt6 기반의 3D FDTD(Finite-Difference Time-Domain) 전자파 시뮬레이터입니다.  
Yee 격자 위에서 전자기장을 시간 진행시키고, 결과를 애니메이션으로 시각화합니다.

---

## 설치 및 실행

```bash
pip install -r requirements.txt
python main.py
```

Python 3.8 이상, PyQt6 · pyqtgraph · numpy가 필요합니다.

---

## 탭별 설정 가이드

### 격자 / 시간

계산 영역의 크기와 시간 진행 파라미터를 설정합니다.

| 항목 | 기본값 | 설명 |
|------|--------|------|
| Nx, Ny, Nz | 100 | 각 축의 격자 셀 수 |
| dx, dy, dz | 1.0 | 셀 간격 (무차원 단위) |
| T | 120.0 | 총 시뮬레이션 시간 |
| dt | 0.5/√3 | 시간 간격 (0 입력 시 Courant 조건으로 자동 계산) |
| c | 1.0 | 빛의 속도 (단위 맞춤용) |
| save_every | 5 | 몇 스텝마다 검광기에 기록할지 |

> **dt 자동 계산**: dt = 0으로 설정하면 `0.5 / (c · √(1/dx² + 1/dy² + 1/dz²))` 으로 Courant 조건을 만족하는 최대값이 사용됩니다.

---

### 광원

전자파를 주입할 소스를 설정합니다. 여러 개 추가 가능합니다.

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 타입 | gaussian_pulse | 가우시안 미분 펄스 (광대역 여기) |
| x, y, z | 50, 15, 50 | 소스 위치 (격자 인덱스) |
| component | Ez | 주입할 전기장 성분: Ex / Ey / Ez |
| amplitude | 3e-3 | 진폭 |
| tau | 8.0 | 펄스 폭 (클수록 좁은 대역) |
| t0 | 30.0 | 펄스 중심 시각 (보통 3~4 × tau) |

> **가우시안 미분 펄스**: 직류 성분이 없어 FDTD 광대역 해석에 적합합니다.  
> t0를 충분히 크게 설정해야 펄스가 t=0에서 완전히 영이 됩니다.

---

### 재질 / 구조

시뮬레이션 영역 안에 물질 구조를 배치합니다. 여러 개 중첩 가능합니다.

**공통 전기적 특성**

| 항목 | 설명 |
|------|------|
| ε (eps) | 비유전율 (기본 1.0 = 진공) |
| μ (mu) | 비투자율 (기본 1.0) |
| σ (cond) | 전도율 (0 = 완전 절연체, 클수록 도체) |

**내장 재질 참조값**

| 재질 | ε | σ |
|------|---|---|
| 진공 (VACUUM) | 1.0 | 0 |
| 구리 (COPPER) | 1.0 | 5.96×10⁷ |
| 금 (GOLD) | 1.0 | 4.1×10⁷ |
| 실리콘 (SILICON) | 11.7 | 0 |
| 유리 (GLASS) | 2.25 | 0 |
| 물 (WATER) | 80.1 | 0 |

**구조 형태**

- **Box** — 직육면체 영역: x0~x1, y0~y1, z0~z1 (격자 인덱스)
- **Sphere** — 구: 중심 (cx, cy, cz), 반지름 r
- **AsymmetricSawtooth** — 비대칭 톱니 구조 (반딧불이 큐티클 모사):
  - z_base: 구조 시작 z 위치
  - height: 톱니 높이
  - period: 주기
  - duty: 완만한 쪽 비율 (0.8 = 80% 완만 / 20% 급경사)

### 검광기

시뮬레이션 중 전자기장을 기록할 단면을 지정합니다. 여러 개 추가 가능합니다.

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 타입 | plane | 2D 단면 기록 |
| axis | y | 법선 축: x / y / z |
| position | 50 | 단면의 격자 인덱스 (0 ~ N-2) |
| quantities | 전체 | 기록할 성분: Ex / Ey / Ez / Hx / Hy / Hz |

> axis=y, position=50 이면 y=50 평면(x-z 평면)의 필드 전체를 매 save_every 스텝마다 기록합니다.

---

### PML 경계

CPML(Convolutional Perfectly Matched Layer) 흡수 경계 조건을 설정합니다.  
계산 영역 외곽에서 전자파를 반사 없이 흡수합니다.

| 항목 | 기본값 | 설명 |
|------|--------|------|
| thickness | 10 | PML 층 두께 (격자 셀 수) |
| R0 | 1e-8 | 목표 반사율 (작을수록 흡수 강함) |
| m | 3 | σ 프로파일 다항식 차수 |
| kappa_max | 1.0 | 좌표 신장 계수 (1.0 = 비활성) |
| alpha_max | 0.0 | CFS-PML 복소 주파수 이동 |
| sigma_max | 자동 | 최대 전도율 (R0, m, thickness로 자동 계산) |

> 일반적으로 기본값으로 충분합니다. 저주파 성분이 잘 흡수되지 않을 때 kappa_max > 1로 높여보세요.

### 시각화

시뮬레이션 결과 `.npz` 파일을 열어 필드 애니메이션을 확인합니다.

**사용 순서**

1. **파일 선택** — 저장 디렉터리에서 검광기 NPZ 파일 선택  
   (`saves/save_TIMESTAMP/검광기 #1.npz` 형식)
2. **필드 선택** — 파일에 기록된 성분 중 하나 선택 (Ex / Ez 등)
3. **재생** — 애니메이션 시작 / 정지 / 슬라이더로 수동 탐색

**표시 옵션**

| 옵션 | 설명 |
|------|------|
| 색상맵 | viridis / plasma / CET-L4 |
| 민감도 | 0.1x ~ 10.0x — 감마 커브로 약한 신호 강조. 1.0x = 선형 |
| eps 오버레이 | 반투명으로 유전율 분포 표시 (검광기 평면 기준 슬라이스) |
| 소스 마커 | 소스 위치를 청록색 점으로 표시 |

> **부호 정보 표시**: 전기장의 양/음 진폭이 모두 표시됩니다. 중앙(0)이 색상 중간값이 되어 파면의 위상, 상쇄간섭, 정상파를 구분할 수 있습니다.

## 실행 흐름

```
1. 각 탭에서 파라미터 입력
2. 왼쪽 하단 "▶ 시뮬레이션 실행" 클릭
3. 설정 확인 다이얼로그 → "실행"
4. 백그라운드 스레드에서 시뮬레이션 진행 (진행률 표시)
5. 완료 후 출력 경로에 자동 저장
6. "시각화" 탭에서 결과 확인
```

---

## 출력 파일 구조

```
saves/
└── save_TIMESTAMP/
    ├── 검광기 #1.npz   ← Ex, Ez 등 기록된 성분 (shape: [프레임, Ny, Nz] 등)
    ├── 검광기 #2.npz   ← 검광기가 2개인 경우
    └── metadata.npz    ← 격자 크기, eps/mu 분포, 소스 위치, 검광기 정보
```

각 검광기 NPZ에는 요청한 필드 성분 배열과 함께 `_det_axis`, `_det_position` 키가 내장되어 있어, 파일 단독으로도 어느 평면을 기록했는지 확인할 수 있습니다.

## 설정 저장 / 불러오기

- **저장**: "설정 저장" → JSON 파일로 내보내기
- **불러오기**: "설정 불러오기" → JSON에서 모든 탭 복원
- JSON에 없는 키는 무시되어 이전 버전 파일도 안전하게 로드됩니다.

## 주의사항

- 격자가 클수록 (Nx·Ny·Nz) 메모리와 시간이 급격히 증가합니다. 테스트 시 50³ 이하를 권장합니다.
- 검광기 position은 `0 ~ N-2` 범위여야 합니다 (Yee 격자의 필드 배열 크기 제약).
- 동일 이름의 검광기를 두 개 추가하면 오류가 발생합니다.
- 시뮬레이션 도중 "중단"을 누르면 해당 시점까지 기록된 데이터가 없으면 파일이 생성되지 않습니다.
